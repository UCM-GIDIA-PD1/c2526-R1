Ejemplo de servidor web con FastAPI

Este servidor ilustra tres conceptos básicos del desarrollo web.

Bloque 1 — Peticiones HTTP básicas (respuesta JSON)

Estos endpoints reciben datos y los devuelven tal cual en formato JSON. Pruébalos desde la documentación interactiva.

  • GET /echo — los parámetros viajan en la URL
  • POST /echo — los parámetros viajan en el cuerpo de la petición

Bloque 2 — Formularios HTML (respuesta HTML)

Estos formularios envían datos al servidor y muestran la respuesta como una página web.

  • Formulario GET → envía a GET /echo/html
  • Formulario POST → envía a POST /echo/html

Bloque 3 — Predicción con modelo de Machine Learning

El servidor carga un modelo entrenado con el dataset Iris y lo usa para clasificar flores.

  • flower1 — formulario HTML básico, envía a POST /iris/predict/html
  • flower2 — mismo formulario con diseño Bootstrap
  • flower3 — llama a POST /iris/predict con fetch() sin recargar la página
  • POST /iris/predict — interfaz JSON pura (ver docs)
